    Connect to data

    Open files from this computer. They are read in your browser and never uploaded.

    A link to a file: Parquet, CSV, GeoPackage, GeoJSON, FlatGeobuf, Excel, or a Zarr store. Large files are read in parts, as queries need them.

    Reading from a database (PostgreSQL/PostGIS, and others) is not available yet.

    A web page cannot talk to a database server directly, so this connector will go through the local GeoMarmot server, which can. In the meantime, export a table to Parquet or GeoPackage and open the file.
